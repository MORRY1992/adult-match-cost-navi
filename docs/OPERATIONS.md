# 大人のマッチング実費ナビ 運営手順

GitHub正本: MORRY1992/adult-match-cost-navi / main
公開先: Cloudflare Pages。URLは公開結果を確認するまで未確定。
初版: 2026-11-02。追加固定費0。有料APIなし。他のサイト変更禁止。

## ファイル
- data/services.json: 正式な料金・条件・項目状態・出典・照合日時。確認できた項目だけ更新。
- data/ad-config.json: 全広告の初期停止設定。承認の証跡、ホスト、日本配信、形式、カテゴリーを分離。
- src/cost.mjs: 税込通常額・オプション・仮定による月払い・ポイント換算。更新後料金はnull。
- scripts/build.mjs: 個別ページ・SEO・CSPを生成。npm run build / 出力dist。
- docs/ops/: 公開・審査・計測状態。実際の収益・本人情報は公開GitHubへ保存しない。

## 日次（既存の8時枠で統合する）
正本の最新SHA、運営手順、サービスJSON、前回の確認失敗を読み、公式公開ページの変更・取得失敗を低頻度で確認。まずWeb検索/正規の取得手段を使う。robotsと各サイトの取得規則を尊重し、無許可の定期スクレイピングはしない。
新データに矛盾がある場合、取得失敗、アプリ内購入額しか分からない場合はpendingとして保持。旧確認日を新しくせず、金額を推定しない。差分候補には対象項目・旧値・新値・公式URL・確認日時・取得状態を記録。

## 毎週月曜19時（既存枠）
料金・更新期限・解約手順・返金・公式リンク・広告コード状態を点検。事業者の届出表示と行政による独立照会を区別。レビュー済みデータ差分だけを保存する。広告設定は自動変更しない。

## 毎月1日19時（既存枠）
同一期間・通貨・媒体・タイムゾーンの公式レポートから visits/PV/impressions/eCPM/clicks/CPA発生/承認/入金/費用/訪問1000回当たり総収益を整理。計測未接続はnull。口座全体を当サイト収益へ割り当てない。比較利用・送客・再訪は専用計測の接続後に評価。性的関心や個人的な入力を広告会社へ送信しない。

## 公開する変更の検証
1. 更新直前にmain最新SHAを取得。競合時は再取得、force上書き禁止。
2. npm test → npm run build → npm run check。確認した出典・変更理由・対象を記録。
3. GitHub保存後、Actions成功・Cloudflare Pages成功・本番JSON一致を別々に確認。GitHub保存だけで公開完了にしない。
4. 公開URLが候補と異なる場合SITE_URLとscripts/check.mjsの正規URL検証を同時更新。検索所有権タグは削除しない。

## 広告
Adsterra現行規約4.2の成人コンテンツ制限、ExoClick無料/shared hosting制限を回避しない。確認前のコード接続禁止。露骨な成人広告は現在の自己申告方式で有効化しない。正規コードは不正改変しない。一般向けASPとの共存は個別許可が必要。本人確認・新規規約同意・費用追加は本人手続き。

## 既存タスクとの分担
Webサイト日次運営・検索対策の既存予定枠に担当D3として追記する。既存H/V/J/R/M5の全文・権限・時刻・公開先を保持。M5は読取・横断管理のみ、D3は本リポジトリの公式確認済みデータ更新に限定。定期実行での広告開始、外部連絡、SNS投稿は行わない。
