# 大人のマッチング実費ナビ Implementation Plan

Goal: 18歳以上向けに、公式確認済み料金と契約条件から支払額を比較できる静的サイトを公開する。
Architecture: Node標準ライブラリのみでJSONから静的ページを生成。計算・広告・運営データを分離する。
Spec: 2026-11-02の本人正式着工命令。実装と公開まで一任、不要な確認を省略。

## Global Constraints
追加固定費ゼロ。他のサイト・自動化枠に影響させない。推測料金、架空連絡先、未承認広告通信を禁止する。

## Review Focus
- 未確認料金はゼロにしない。
- 複数月の月額換算と契約請求額を区別する。
- ポイント消費換算と現金購入額を区別する。
- 更新後未確認は料金継続を断定しない。
- 広告未承認・別ホスト・年齢確認不足では通信しない。

## Tasks
- [ ] Task 1: 計算・広告許可判定のテストを先に実行して失敗を確認し、src/cost.mjs、src/ad-policy.mjsに実装する。
- [ ] Task 2: data/services.jsonに5サービスの確認状態・公式出典・日付を記録する。scripts/build.mjsでトップ、サービス、比較ガイド、共通ページとSEOを生成する。
- [ ] Task 3: public/assets/app.mjsとstyle.cssでモバイル操作、期間・支払経路・オプション・目的フィルターを実装する。
- [ ] Task 4: data/ad-config.jsonを初期停止にし、収益台帳・変更検出を準備する。既存自動化は読んでから非破壊で統合する。
- [ ] Task 5: npm test、npm run build、生成物検査、ブラウザー操作を確認し、GitHubに保存する。
- [ ] Task 6: Cloudflare Pagesを作成し、実URLで確認する。認証が必要なら成果物を先に完成し、必要部分のみ引き継ぐ。広告は正式承認後のみ接続。

## Rulings
- デザインと実装方法の一任に基づき、クリーム・深緑・コーラルの読みやすい情報サイトを採用。
- 広告会社の成人向け対応は媒体受入と広告カテゴリー許可を別々に記録する。
- 2026-11-02確認のAdsterra規約4.2(iii)に成人向けコンテンツ制限がある。書面確認なく成人広告を開始しない。
